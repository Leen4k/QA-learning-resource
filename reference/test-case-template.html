Handoff gate

  • Every case traces to a distinct target or a named interface risk.
  • The starting state can be recreated without asking the author.
  • The action names the actor, interface, target and concrete data.
  • The expected result is observable and states what must remain unchanged.
  • Normal, invalid and relevant boundary behavior are represented.
  • Setup and reset order are explicit where cases change shared state.
  • Uncovered risks are listed; a green case count never means “fully tested.”
